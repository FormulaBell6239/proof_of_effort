# Trademarks & Brand Use Policy

This repository is licensed under the **MIT License** (see `LICENSE`).

**Important:** The MIT License grants permissions to use the code, but it **does not grant permission** to use the project’s **name, logos, or other trademarks/brand identifiers**.

This file is a simple, human-readable policy intended to prevent confusion and impersonation (including “official-looking” forks).

## Names and marks covered

For the purposes of this policy, the “Marks” include:

- The names **“Proof of Effort”** and **“Proof-of-Effort Network”**
- Any project logos, wordmarks, or distinctive visual branding associated with this repository
- Any names, icons, or branding that are confusingly similar

## You may (generally) ✅

- Fork this repository and modify the code.
- Run your own instance of the software.
- Use the code commercially (MIT permits this).
- Write blog posts, tutorials, or reviews that reference the project by name (nominative use).
- State factual compatibility (e.g., “compatible with Proof of Effort APIs”) as long as it’s not misleading.

## You may not ❌

- Use the Marks in any way that is likely to cause confusion about the source of goods/services or about affiliation, sponsorship, or endorsement.
- Use the Marks (name/logo/branding) in a way that suggests your fork or service is **official**, **endorsed**, **certified**, or **operated by** the original project maintainers.
- Use the Marks for a product/service name (especially a hosted service) in a way that could confuse users.
- Use the project logo (or confusingly similar branding) for forks without explicit, written permission.
- Claim you are the original authors/maintainers, or misrepresent your relationship to the project.

- Register or use confusingly similar **domain names**, **social media handles**, or **app store listings** that imply this project is the official source.
- Present yourself as official “support” for the project, or use the Marks in phishing/scam flows (including asking for seed phrases, private keys, passwords, or other credentials).

## Guidance for forks (recommended)

If you fork and publish a modified or hosted version:

- **Rename** your project/service (pick a distinct name).
- **Remove/replace** logos and branding assets.
- Add a clear note such as: “This is an independent fork and is not affiliated with or endorsed by the Proof of Effort project.”

## Anonymous maintainers (privacy note)

This project may be maintained by contributors who prefer to remain anonymous. This policy exists to reduce user confusion and impersonation risk, not to require disclosure of anyone’s real-world identity.

## Permission requests

If you want to use the Marks (e.g., for an official partnership, a certified integration, or sharing the logo), please open a GitHub issue describing your intended use.

This is not legal advice. If you need formal trademark protection or enforcement, consult a qualified attorney.
