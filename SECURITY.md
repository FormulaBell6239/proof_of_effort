# Security Policy

Thanks for helping keep Proof of Effort safe.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive bugs.

Preferred:
- Use **GitHub Security Advisories** ("Report a vulnerability") on this repository.

If the advisory feature isn’t available:
- Open a GitHub issue with the title **"Security: private disclosure requested"** and **do not include exploit details**. A maintainer will respond with a safer channel.

## What to include

- A clear description of the issue and affected component(s)
- Steps to reproduce (proof-of-concept if possible)
- Impact assessment (what an attacker can do)
- Any suggested fix/mitigation

## Scope

This project includes a backend API, a frontend web app, and smart contracts. Please clearly state which area is affected.

## Safe harbor

We support good-faith security research. Please avoid actions that could harm users, expose private data, or disrupt service.

## Response expectations

We’ll do our best to:
- Acknowledge receipt within a reasonable time
- Work on a fix and coordinate a responsible disclosure

(Policy is informational and not a legal agreement.)
